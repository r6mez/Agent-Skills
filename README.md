# Agent Skills

A collection of skills I created to do various stuff.

| Skill | What it does |
| --- | --- |
| [obsidian](obsidian/SKILL.md) | Writes and formats notes in Obsidian-flavored Markdown. |
| [study-summary](study-summary/SKILL.md) | Turns a lecture's notes, slides or code into an interactive HTML study page and PDF for exam prep. |
| [exam-solution](exam-solution/SKILL.md) | Turns a past exam paper into an HTML replica with handwritten-style answers (or a clean unsolved copy), plus a PDF. |
